## 4. Источник перехода определился

Ссылка собирается с метками `utm_source`, `utm_medium`, `utm_campaign`
и открывается на своём сайте.

**Ссылка целиком:**

```
https://ga4-analytics-lab-stvxs.vercel.app/?utm_source=homework&utm_medium=referral&utm_campaign=hw03
```

| Поле | Значение |
|---|---|
| Где в GA4 виден источник | Пока не отображается; отчёт «Привлечение трафика» показывает нули |
| Какое значение источника показал GA4 | Пока не определено |
| Совпадает с `utm_source` из ссылки | Пока нельзя подтвердить |

Скриншот: ![Источник перехода в GA4](screens/04-source.png)`

>На момент проверки в Realtime отображались события page_view и session_start, но стандартный отчёт о привлечении трафика пока не содержал данных.

Скриншот отчёта будет добавлен после появления данных: screens/04-source.png.

Источник и кампания из UTM в отчёте Realtime не показываются: эти измерения
вычисляются при обработке данных. Если в Realtime источника нет, смотрите
отчёт по источникам трафика в разделе «Отчёты».
